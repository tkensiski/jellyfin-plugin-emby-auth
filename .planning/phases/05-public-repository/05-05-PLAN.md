<objective>
Build the PUB-01 pre-publication audit as a tracked script, run it, and hand the result and the visibility command to the maintainer.

Purpose: publishing is irreversible for anyone who copies the repository in the interval. Before that happens, the full git history must be scanned for secrets and the Actions logs and artifacts, the issue and pull request text, and the release notes must be reviewed. The scan half reuses the continuous check plan 05-03 already wired into `mise run lint`, so the pre-publication scan is something the pre-commit hook and CI have been proving on every commit rather than a one-time event. The review half is evidence a human reads.
Output: `scripts/pre-public-audit.sh`, `tests/scripts/pre-public-audit.bats`, a completed audit report, and a decision checkpoint that stops the phase in the maintainer's hands.

**PUB-03 cannot be completed from inside this execution run, by design.** The phase ends at the checkpoint. Verification that the repository is public happens afterwards, with `gh repo view --json visibility`.
</objective>
