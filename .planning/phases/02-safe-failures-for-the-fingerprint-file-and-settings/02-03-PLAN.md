<objective>
Close FPRT-02: when Jellyfin cannot read the fingerprint file, a later accepted login does not replace it, and every record that was in it is still in it.

Purpose: `Load()` assigns an empty dictionary to the cache field **before** it reads the file (`EmbyVerifiedPasswords.cs:97`). A caught read failure therefore leaves that empty dictionary cached for the life of the process, and the next `Record` adds one entry to it and writes the whole map back through the atomic replace at `:56-58`. One unreadable read destroys every record in the file, silently, and only a Jellyfin restart can change the outcome. Every user then has to log in through Emby again before any of them can move to the Default login method.

Output: a `Load()` that caches only what it successfully read, a `Record` that writes nothing while the read fails, and three tests that fail against the current code.
</objective>
