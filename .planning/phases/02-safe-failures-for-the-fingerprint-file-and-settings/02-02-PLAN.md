<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Jellyfin plugin API → the settings page script | A rejected request's error value crosses into the browser and can carry the request URL, which is the configured Emby address, which can embed a user name and password. |
| Emby-controlled data → the settings page DOM | Emby user names reach `#EmbyAuthMigrationUsers` through `GET /EmbyAuth/Migration`. An Emby administrator chooses those names; this plugin does not. |
| The administrator's browser → the stored plugin configuration | A Save writes the four input values over the stored settings. |

| T-02-01 | Information Disclosure | the save-failure message written to `#EmbyAuthMigrationSummary` | high | mitigate | The message is a string literal, never built from the rejection value or from `config.EmbyServerUrl` / `config.EmbyApiKey`.
